## What's Changed

- **Self-heal a broken Homebrew install of Mole.** If Mole's own wrapper script fails because its Homebrew Cellar files are missing — e.g. after an interrupted `brew upgrade` or a Migration Assistant transfer that didn't carry over Homebrew's internal symlinks — MacMoleManager now recognizes that failure and offers a one-click **"Reinstall via Homebrew"** fix instead of a raw shell error. If Homebrew's own reinstall then fails to relink (a separate, common Homebrew failure), it automatically retries with `brew link --overwrite` before giving up. If Homebrew still can't recover, a second button, **"Install Mole Directly,"** bypasses Homebrew entirely using Mole's own installer — no need to uninstall anything first.
- **Added an automated release pipeline.** Pushing a version tag now builds, signs, notarizes, staples, and publishes a GitHub release automatically via GitHub Actions — both a `.zip` (direct download) and a fleet-deployable `.pkg` (Mole pre-staged via postinstall). This release is the first one built and published through it.
